## 🎯 The Problem

When using Google Antigravity or AI coding agents for 3D CAD (`build123d`, OpenSCAD, Blender) or 3D printing:
1. **Broken Side Panel Previews:** Antigravity's auxiliary pane previewer fails on `.3mf` archives (treating them as raw binary) and renders `.stl` meshes with flat, low-contrast shading.
2. **The "File Link" Trap:** Clicking bare `file:///` handles opens the broken internal preview tab rather than launching your slicer.
3. **Too Many Clicks:** Getting a model into Bambu Studio requires *Right Click $\to$ Reveal in Finder $\to$ Double Click in Finder*.
4. **File Spam:** Agents often emit 20 separate piece files instead of a clean, single combined 3MF container.

---

## 🚀 The Solution

`antigravity-bambu-bridge` connects your Antigravity agent directly to **Bambu Studio** (and OrcaSlicer / PrusaSlicer):

- **1-Click Native Slicer Launch:** Instantly loads the model directly onto your virtual build plate.
- **Near-0 LLM Token Overhead:** Clicking the button costs **exactly 0 tokens** (pure client-side loopback fetch to a background daemon; the AI model is never called). The chat embed itself takes only $\approx 15$ tokens.
- **Native 3MF Plate Renders:** Automatically unpacks and displays the slice preview render (`Metadata/plate_1.png`) generated by Bambu Studio.
- **Responsive Layout:** Sleek top bar (title + size + badge + launch button) with a large preview below. Automatically wraps to 3 rows on narrow screens or long filenames.
- **Zero Dependencies:** Pure Python standard library (`http.server`, `zipfile`, `base64`). Consumes `< 10 MB` RAM, `0%` CPU idle.

## 📦 Quick Installation

Run the one-line installer in your terminal:

```bash
git clone https://github.com/your-username/antigravity-bambu-bridge.git
cd antigravity-bambu-bridge
./install.sh
```

### What `install.sh` does:
1. Installs `bambu-bridge.py` and `bambu-card.py` to `~/.local/bin/`.
2. Registers and starts a background `LaunchAgent` on macOS (starts on login, auto-restarts).
3. Installs the Antigravity plugin rule to `~/.gemini/config/plugins/bambu-bridge/` so all current and future projects automatically adopt the behavior.

```text
                            │
                            │ LaunchServices / xdg-open
                            ▼
              [ Bambu Studio / OrcaSlicer ]
```

## ⚙️ Configuration

You can customize the port and target slicer via environment variables:

| Variable | Default | Description |
| :--- | :--- | :--- |
| `BAMBU_BRIDGE_PORT` | `48921` | Local loopback HTTP port for the daemon |
| `BAMBU_SLICER_APP` | `/Applications/BambuStudio.app` | Path or name of the target slicer (e.g. `OrcaSlicer`) |

## 🗑️ Uninstallation

To completely remove the background service, binaries, and Antigravity plugin:

```bash
cd antigravity-bambu-bridge
./uninstall.sh
```
